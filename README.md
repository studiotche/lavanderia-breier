# Lavanderia Breier

Site institucional da Lavanderia Breier, desenvolvido em Astro.

O conteúdo público foi organizado a partir do perfil do Google Maps e do Instagram `@lavanderiabreier`. A coleta bruta, os dados normalizados e as imagens de referência ficam em [`imagens-google-maps`](./imagens-google-maps).

## Dados confirmados na coleta

- Av. Pres. Lucena, 2084 — Concórdia, Novo Hamburgo/RS
- Telefone exibido no Google Maps: (51) 3563-6908
- Instagram: [@lavanderiabreier](https://www.instagram.com/lavanderiabreier/)

O perfil do Google Maps sinaliza que o cadastro pode estar fechado ou precisar de atualização. Por isso, o site informa que os horários devem ser confirmados antes da visita.
